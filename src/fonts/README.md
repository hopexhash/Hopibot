# Fonts stored in the repository

`GeneralSans-Variable.woff2` is General Sans by Indian Type Foundry, from Fontshare
(https://www.fontshare.com/fonts/general-sans), under the ITF Free Font License: free for
personal and commercial use, including on websites. It is stored here because it is not on
Google Fonts; the website serves it itself, so no visitor request goes to a third party.
The file may not be sold or offered for download on its own.

Space Grotesk and IBM Plex Mono come from Google Fonts through `next/font`, which also serves
them from the website's own domain.

`PlexSansZero.woff2` is a single character, the zero, cut from IBM Plex Sans Medium (SIL Open
Font License). It replaces the dotted zero of IBM Plex Mono in labels; see `src/lib/site/fonts.ts`.
